# Traktion

Traktion is a full-stack fitness tracking application built with React Native, Node.js, and PostgreSQL. It combines a custom workout builder with automatic rest timers and PR detection, a food logging system with macro tracking, and an optional social feed — all wrapped in a distinctive blue-and-black design.

This project was built as a personal deep-dive into full-stack mobile development, covering everything from database design to UI/UX and deployment.

## Features
- Custom workout builder with per-exercise rest timers
- Automatic personal record (PR) detection
- Progress charts per exercise (weight & volume over time)
- Food logging with macro breakdown and daily calorie tracking
- Optional social feed to share workouts with friends
- Blue/black design system

## Tech Stack
- **Mobile:** React Native (Expo) + TypeScript
- **Backend:** Node.js + Express + TypeScript
- **Database:** PostgreSQL + Prisma ORM
- **Website:** Next.js
