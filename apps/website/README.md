# Traktion Website

Next.js (App Router) + TypeScript marketing/companion site for Traktion.

## Getting started

```bash
npm install        # from repo root (npm workspaces)
npm run dev        # from this directory, or `npm run dev:website` from repo root
```

Open [http://localhost:3000](http://localhost:3000).

## Notes

- Built in Phase 5 as a single-page portfolio site: hero, features grouped by phase, tech
  stack, and a GitHub link — reusing the mobile app's blue/black palette and Barlow/Barlow
  Condensed fonts so the site and the app read as one brand. See `/DEVELOPMENT_LOG.md` at the
  repo root for the full write-up, and `/DEPLOYMENT.md` for how to deploy it (Vercel).
- Fully static — no environment variables, no API calls, no database. `npx next build` reports
  the homepage as `○` (static), which is also why it deploys with zero config on Vercel.
- `AGENTS.md` / `CLAUDE.md` are auto-generated by `next dev` (official Next.js agent-rules block) — safe to keep, they get re-created automatically.
